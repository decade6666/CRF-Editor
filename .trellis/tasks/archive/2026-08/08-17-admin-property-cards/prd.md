# 管理端与属性卡体验修复

## Goal

消除管理端的无效留白和页面切换重载，统一机构管理与用户管理的编辑模式；同时让单位、访视和表单设计器的编辑反馈更稳定、紧凑且符合既有列表/属性卡交互。

## Requirements

### 管理端

1. **机构管理页面**
   - 机构预设列表应占用管理端可用表格宽度，不保留当前固定的右侧编辑空白区域。
   - 删除“点击左侧机构进行编辑，或点击「新增预设」创建机构。”及两页不必要的页面说明文字。
   - 新增和编辑机构预设均通过 Element Plus 弹窗完成；弹窗保留名称、数据管理单位、Logo 上传/替换/清除功能，以及现有校验、错误提示、Logo URL 生命周期管理和键盘预览能力。
   - Logo 预览继续支持点击遮罩关闭。

2. **管理页面切换**
   - 在用户管理和机构管理之间切换时保留已加载组件状态和机构 Logo blob URL，避免每次切换重新请求列表和所有 Logo。
   - 手动“刷新”仍按现有语义重新拉取当前页面数据。

3. **项目列表与删除提示**
   - 项目列表弹窗的选择列复选框在表头和内容行均居中。
   - 复制和迁移的目标用户候选都排除源用户。
   - 项目普通删除与批量删除是软删除，确认文案必须表达“删除后如需恢复，请联系管理员。”；回收站“彻底删除”仍明确不可恢复。

4. **用户表视觉留白**
   - 用户名列可随管理端宽壳扩展，避免固定窄列后留下无意义的大块表格空白。

### 用户端

5. **表单 Word 预览顶栏备注**
   - 表单名称、设计备注 chip、字段数量保持单行；空间不足时优先截断可收缩文本，而不是把整组内容换到下一行。
   - 保持 chip 的胶囊视觉、tooltip 多行展示与无障碍触发语义。

6. **单位与访视属性编辑**
   - `UnitsTab` 和 `VisitsTab` 的常规列表页采用与 `FieldsTab` 相同的“左侧列表 + 右侧 320px 属性卡”结构：标题槽位在卡片边框外，表格与卡片顶边对齐。
   - 点击行进入编辑；新增进入同一属性卡；保存/取消在属性卡内完成；无选中项时显示明确空态。
   - 单位卡编辑 OID（完整模式）和单位符号；访视卡编辑 OID（完整模式）和访视名称。
   - 访视序号不进入属性卡，继续只通过现有拖拽和序号双击快编维护。
   - 移除 UnitsTab/VisitsTab 的新增/编辑弹窗，以及操作列的 EditPen 按钮；单位行只保留删除，访视行保留复制和删除。
   - 现有搜索、批量删除、引用影响确认、拖拽排序、序号快编、访视流程矩阵/单访视视图、预览与排序行为必须保持。

7. **访视矩阵**
   - 在访视流程矩阵取消勾选表单时直接删除关联，不显示二次确认；单访视视图的无确认移除语义保持一致。

8. **表单设计器**
   - 三面板只显示 resizer 负责的一条分隔线；字段面板不得因继承通用 `.fd-canvas` 样式额外渲染内缘边框或阴影。
   - 保存新增字段后，无论服务端字段列表刷新是否被会话守卫吞掉，均要选中新创建字段；属性面板不得停留在失效草稿状态。

## Constraints

- 不修改后端 API、数据库模式、删除语义或项目回收站逻辑。
- 不新增依赖；继续使用 Vue 3、Element Plus、既有 `useApi`、`useSortableTable`、`useOrdinalQuickEdit`、`rankFuzzyMatches` 和 `confirmDelete` 模式。
- 不使用负 margin，不运行 `npm run format`，不引入生产 `console.log`。
- 保持完整模式 OID 显示约定、全局表头居中约定、子路径 `apiUrl()` 边界约定和现有无障碍标签。

## Acceptance Criteria

- [ ] 机构管理为全宽列表 + 新增/编辑弹窗；不存在右侧编辑占位区或“点击左侧机构…”说明。
- [ ] 用户/机构页面反复切换不重新触发各自的 mount 加载；已加载 Logo 预览可继续使用，退出时仍释放 URL。
- [ ] 项目列表选择列视觉居中，复制/迁移候选没有源用户。
- [ ] 项目软删两个确认层级和管理员批量软删均提示“删除后如需恢复，请联系管理员。”；回收站彻底删除仍提示不可恢复。
- [ ] Word 预览顶栏在窄宽度下不把备注/名称组换行，备注内容以 ellipsis 截断且 tooltip 保持。
- [ ] UnitsTab 与 VisitsTab 常规列表页有对齐的右侧属性卡，新增、点行编辑、保存、取消、删除后清理选择状态都可用；无新增/编辑弹窗与 EditPen 行操作。
- [ ] 访视属性卡不含序号；拖拽和双击序号快编仍可用。
- [ ] 矩阵取消勾选与单访视移除均无二次确认，失败仍可见错误消息。
- [ ] 设计器字段面板无继承的内缘 border/box-shadow，resizer 是唯一内部分隔线。
- [ ] 新字段保存后立即选中真实字段行，随后修改可保存。
- [ ] 所有相关前端测试、lint、构建通过；后端回归基线通过；管理员与普通用户浏览器路径完成验证。
