# 访视流程页面化

## Goal

将默认访视页收敛为纯全宽列表，并把「批量编辑」弹窗中的访视—表单矩阵改为页面内工作区；访视流程提供矩阵 / 单访视表单两种页面内视图。改动收敛于前端 `VisitsTab.vue`，零后端变化。

## Background

父任务 `08-13-admin-editor-interaction-refactor` R3。现状：`VisitsTab.vue` 同时承载访视列表、右侧「访视内表单」工作区、矩阵弹窗（`showPreview`）与表单预览弹窗；「批量编辑」按钮仅置真 `showPreview`，矩阵主体位于 `el-dialog` 内（`VisitsTab.vue:755-945`）。单访视表单维护能力（选择、添加、排序、预览、移除）已完整存在且复用现有 API（`reloadVisitForms()`）。

## Requirements

### R1 默认访视页：纯全宽列表
- 删除「批量编辑」按钮与右侧「访视内表单」工作区；页面只呈现全宽访视列表。
- 列表模式保留现有全部访视管理能力：新增、复制、编辑、删除、批量删除、搜索、拖拽排序、序号快编。
- 工具栏最右侧增加「访视流程」入口，点击进入页面内工作区，再次点击返回列表。

### R2 访视流程工作区（页面内，不弹窗）
- 进入后默认矩阵视图，矩阵在页面内直接渲染（原弹窗标记去 `el-dialog` 包装）。
- 矩阵语义沿用现有实现：点击单元格切换关联（移除需确认），数字为序号，空数据提示保留。
- 提供类似编辑模式（App.vue 设置弹窗 `el-switch` inline-prompt）的二态切换控件，可在矩阵 / 单访视两视图间切换；控件使用 small 尺寸以保持共享标题槽的 36–37px 高度契约。

### R3 流程模式只读边界
- 禁止所有访视新增 / 复制 / 编辑 / 删除 / 批量删除：单访视视图左侧列表仅用于选择已有访视，不渲染任何访视 CRUD 控件、选择列、拖拽把手、序号快编。
- 右侧面板保留为已有访视添加表单、拖拽排序、序号快编、预览、移除的全部能力。

### R4 生命周期与状态保持
- 视图切换（矩阵 ↔ 单访视）与模式切换（列表 ↔ 流程）不得丢失数据：`visits` / `matrixData` / `allForms` / `selectedVisit` 保持，不触发重新加载。
- 项目切换复位：退出流程模式、视图复位矩阵默认、清空选中访视与预览状态（沿用现有 flush / close / load 顺序）。
- 模式 / 视图切换导致表格 DOM 重挂后，拖拽排序必须重新初始化。
- 表单内容预览弹窗（含 eCRF / aCRF 切换与 aCRF 标注垂直拖拽）保留；模式 / 视图切换不关闭弹窗。

### R5 约束
- 零后端变化、零新 API；不改变访视—表单关系、排序、确认（`confirmDelete`）语义。
- 不修改预览渲染、列宽 / 行高规划、aCRF 标注几何（跨栈契约零影响）。
- 不修改 `App.vue`、`useSortableTable.js`、`useOrdinalQuickEdit.js`、`useLazyTabs.js`。

## Acceptance Criteria

- [ ] AC1：默认访视页只显示全宽访视列表，无「批量编辑」、无右侧面板；现有访视管理操作全部正常。
- [ ] AC2：工具栏右侧有「访视流程」入口；点击进入页面内工作区且默认矩阵视图；再次点击返回列表。
- [ ] AC3：矩阵页面内呈现（无 `el-dialog` 包装），单元格切换关联与移除确认语义不变，空态提示保留。
- [ ] AC4：二态控件在矩阵 / 单访视间切换，使用 small 尺寸且不撑高共享标题槽；切换不丢失当前数据（选中访视保持）。
- [ ] AC5：单访视视图左列表只读（无 CRUD / 选择列 / 拖拽把手 / 序号快编）；右侧保留添加、排序（拖拽 + 快编）、预览、移除。
- [ ] AC6：项目切换后回到默认列表模式，选中访视与预览状态复位。
- [ ] AC7：模式 / 视图切换后访视与访视表单拖拽排序均可用。
- [ ] AC8：表单预览弹窗保留（含 eCRF / aCRF 与标注拖拽），模式切换不关闭，项目切换按现有语义关闭。
- [ ] AC9：前端全量测试、lint、build 通过；浏览器实机验证三态 + 明暗主题，未运行项必须明确说明。
