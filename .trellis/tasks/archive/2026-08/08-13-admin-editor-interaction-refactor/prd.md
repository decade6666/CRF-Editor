# 管理端与编辑器交互重构

## Goal

重整管理员入口、机构预设、模板入口、访视流程与多处编辑器布局，使高频能力直接呈现在所属页面；同时修复表单设计器草稿链接共享字段后定义级修改丢失，以及该保存动作撤销/重做不完整的问题。

## Background / Confirmed Facts

- 管理员登录后当前直接进入单一 `AdminView`，无管理员级导航；机构预设由弹窗承载，旧结构被 `frontend/tests/adminViewStructure.test.js:11-19` 锁定（`frontend/src/App.vue:1078-1103`）。
- 机构预设 CRUD、Logo 上传/读取及权限边界已经存在。当前编辑代码错误请求 `/api/admin/organization-presets/{id}/logo`，真实读取接口是 `/api/organization-presets/{id}/logo`，且原异常被静默忽略（`frontend/src/components/OrganizationPresetsDialog.vue:62-72`；`backend/src/routers/organization_presets.py:46-137`）。
- 访视列表、单访视表单维护及访视—表单矩阵均已位于 `VisitsTab.vue`；“批量编辑”只打开矩阵弹窗，关系 API 无需改变（`frontend/src/components/VisitsTab.vue:755-945`）。
- “导入模板”位于全局顶栏，导入状态/弹窗/成功后的 `refreshKey++` 均由 `App.vue` 持有；可由 FormDesigner emit 复用而无需复制流程（`frontend/src/App.vue:614-704,1137-1149`；`frontend/src/components/FormDesignerTab.vue:3289-3300`）。
- 五类列表工具栏使用分散的内联 flex/gap/margin；双栏错位来自不同的顶部工具区高度，应建立共享工具栏/顶部槽契约而非页面级像素补丁。
- 草稿丢失根因已确认：候选链接分支只发送 `binding: existing + instance.upsert`，没有提交定义级修改；旧测试还锁定该行为。已持久化字段的候选换绑则使用 `update_shared`（`frontend/src/composables/formDesignerPropertyEditor.js:105-123,149-175`；`frontend/tests/fieldProfileCommands.test.js:108-115`）。

完整调查与多模型交叉核验见 `research/multimodel-evidence.md`。

## Requirements

### R1 管理员入口与机构管理

- 管理员工作区顶部常驻两个并列页面级入口：`用户管理`、`机构管理`；默认用户管理，在同一壳层切换，无入口首页、侧栏或刷新。
- 用户管理继续承载现有用户 CRUD、密码、项目批量操作、回收站和清理策略；其半宽布局不变。
- 机构管理不再以弹窗作为主编辑载体，采用“左侧列表持续可见 + 右侧页面内编辑区”；≤900px 上下堆叠，机构页可使用独立宽壳。
- Logo 上传保存后列表立即显示缩略图；点击使用图片组件内置预览器放大，支持 Esc、Tab、Enter/Space 和可访问名称，不新增自定义预览弹窗。
- 编辑回显和缩略图统一使用正确 Logo URL；直接 Blob/FormData 请求必须通过 `apiUrl()` + `getAuthHeaders()`，加载失败可观察。创建的 Object URL 在替换、清除、删除、切换和卸载时释放。
- 管理员 CRUD 权限、普通用户候选脱敏、位图白名单/魔数/安全路径校验保持不变。

### R2 模板入口与工具栏一致性

- 全局顶栏移除“导入模板”；入口只出现在表单列表工具栏，顺序为 `新建 → 搜索框 → 导入模板 → 批量删除`。
- 导入业务状态继续由 `App.vue` 单点持有；`FormDesignerTab` 仅发出事件，成功刷新沿用现有 `refreshKey`。
- 选项、单位、字段、表单、访视的同类工具栏统一 8px 控件间距、24px small 控件高与 12px 底距；禁止负 margin 和页面私有补丁。

### R3 访视与访视流程

- 默认访视页删除“批量编辑”和右侧访视内表单区，仅显示全宽访视列表；原访视新增、复制、编辑、删除、批删、搜索、拖拽和序号快编继续可用。
- 工具栏右侧增加“访视流程”入口；进入后默认在页面内显示原访视—表单矩阵，不使用弹窗。
- 访视流程提供矩阵 / 单访视二态切换。单访视视图左侧只选择已有访视，不提供访视 CRUD、选择、拖拽或序号快编；右侧保留表单添加、移除、预览、拖拽排序与序号快编。
- 视图切换不重新加载数据；项目切换复位到默认访视列表。条件挂载后 Sortable 和当前行高亮正确恢复；流程切换控件使用 small 尺寸，根容器不叠加私有 gap，继续满足共享槽高度与间距契约。
- 表单预览弹窗、eCRF/aCRF、注记拖拽、列宽/行高和访视—表单关系语义不变。

### R4 双栏垂直对齐

- 选项、字段、表单等双栏页面使用同一等高顶部工具槽；有操作侧显示工具栏，无操作/标题侧保留结构性槽。
- 共享槽目标为 36px；带 1px 底边框标题允许 37px，浏览器实测偏差不得超过 1px。
- FormDesigner 画布头中的默认尺寸 switch 同步收敛为 small，避免控件重新撑高。

### R5 表单设计器视觉与草稿保存

- 只调整字段列表、实时预览、属性编辑三块主工作区的相邻边界：由 6px resizer 热区中央绘一条 1px 分隔线，面板移除内缘但保留外缘；宽屏与 ≤1100px 堆叠均成立。
- 字段列表中的 `.ff-item` 独立卡片、选中、悬停、拖拽和键盘交互不变。
- 草稿链接候选且 OID 未改时：定义级 9 键有差异则 `update_shared` 同一候选定义，无差异则纯绑定；实例级属性只作用当前表单。更新载荷保留候选未暴露的 legacy 结构字段。
- 多表单引用时复用现有影响范围确认；取消/关闭必须保留草稿且不发请求、不进入 busy/mutation。
- 改动候选 OID 继续分叉新定义。
- 保存仍只记录一条历史；undo 恢复共享定义保存前快照并删除实例，redo 重放共享更新并恢复实例。共享候选不得被 cleanup；失败保栈可重试。

## Acceptance Criteria

- [ ] AC1：管理员顶部双入口可切换；用户管理全部既有能力可访问，普通用户看不到管理员入口。
- [ ] AC2：机构预设在页面内完成列表/新增/编辑/删除/Logo 操作，桌面双栏、窄屏堆叠，主流程无机构弹窗。
- [ ] AC3：Logo 保存后立即显示缩略图；鼠标与键盘可打开内置预览；正确 URL、子路径、安全权限和 Object URL 生命周期有自动化/实机证据，失败不静默。
- [ ] AC4：“导入模板”只在表单列表工具栏，顺序为搜索框 → 导入模板 → 批删（新建在首位）；导入预览/执行/刷新行为不变。
- [ ] AC5：选项、单位、字段、表单、访视消费共享工具栏规则；源码无负 margin 补丁，明暗主题间距一致。
- [ ] AC6：默认访视页只有全宽列表，无批量编辑和右侧关系面板；原列表管理能力不退化。
- [ ] AC7：访视流程为页面内矩阵/单访视双视图；切换不丢数据，项目切换复位，重挂后的排序和高亮可用。
- [ ] AC8：单访视左侧不能维护访视，右侧完整保留已有访视的表单关系维护与预览。
- [ ] AC9：选项、字段、表单双栏顶部/有效高度偏差 ≤1px，无负 margin；访视流程使用同一槽位契约，small switch 不撑高且根容器无重复 gap。
- [ ] AC10：设计器三块主工作区相邻处各只有一条 1px 线，外缘完整、6px 拖拽热区/高亮保留；字段条目不退化。
- [ ] AC11：草稿链接候选后修改定义级属性并保存，OID 未改时同一共享定义更新且隐藏 legacy 字段不变；实例级仅当前表单；多引用先确认；改 OID 仍分叉；先红后绿回归覆盖。
- [ ] AC12：上述保存的 undo/redo 作为一条逻辑动作恢复/重放定义与实例，不误删共享候选；失败命令保留可重试。
- [ ] AC13：四个子任务定向测试、前端全量、lint、build、后端全量与浏览器目标场景完成；任何 not-run/failed 项明确报告。

## Scope / Out of Scope

- 计划为前端零后端变化；若实施验证发现接口缺口，返回 Plan，不自动扩大后端、数据库或 API 契约。
- 不新增依赖、路由框架、数据迁移、localStorage 键或自定义 Logo 预览器。
- 不重构 VisitsTab 的预览子系统，不改变 aCRF 几何、Word parity、宽度规划或表单关系 API。
- 不修改 `.ff-item` 字段条目卡片视觉。
- 提交、推送、PR 与 worktree 清理遵循显式授权；main 仅经 PR/CI 自动合并。
